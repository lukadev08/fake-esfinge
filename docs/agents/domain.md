# Documentação de domínio

Este repositório usa o layout single-context: `CONTEXT.md` na raiz e ADRs em `docs/adr/`.

Antes de explorar uma área, leia `CONTEXT.md` e os ADRs pertinentes, quando existirem. A ausência desses arquivos não bloqueia o trabalho; o skill `domain-modeling` os cria quando termos e decisões forem definidos.

Use os termos do glossário em issues, propostas e testes. Se um conceito necessário não estiver descrito, registre a lacuna para `domain-modeling`. Se uma proposta contrariar um ADR, indique o conflito e a decisão que precisaria ser revista.
