# Rótulos de triagem

Os nomes à esquerda são os papéis canônicos dos skills; os nomes à direita são os rótulos usados neste repositório.

| Papel | Rótulo | Significado |
|---|---|---|
| `needs-triage` | `needs-triage` | Aguarda avaliação |
| `needs-info` | `needs-info` | Aguarda informação de quem relatou |
| `ready-for-agent` | `ready-for-agent` | Especificada para execução por agente |
| `ready-for-human` | `ready-for-human` | Requer implementação humana |
| `wontfix` | `wontfix` | Não será atendida |

Ao aplicar um papel, use o rótulo correspondente da segunda coluna.
